1. The kernel page table's aliases for user pages must have PTE_U cleared, because supervisor-mode loads cannot access pages marked user-accessible when SUM is disabled. The mappings must be valid and readable for copyin/copyinstr; retaining the user page's other permission bits is appropriate.

2. With 64-bit unsigned arithmetic, let p->sz be 0xfffffffffffffff0, srcva be 0xffffffffffffffe0, and len be 0x30. Then srcva is less than p->sz, so the first check is false. srcva + len wraps to 0x10, which is also less than p->sz, so the second check is false. But 0x10 < srcva, so the third check detects the overflow and rejects the range. These values illustrate unsigned overflow; xv6's actual user-size limit is much lower.
